# Monitoring dostupnosti zdravotnej starostlivosti

## Zadanie projektu

**Zadávateľ:** RNDr. Igor Kossaczký, CSc.

Navrhnúť a implementovať službu na zdieľanie skúseností a informácií o dostupnosti zdravotnej starostlivosti.

Služba by umožňovala klientom (pacientom) zaznamenať dva kľúčové parametre dostupnosti:

- Čas, ktorý uplynul od okamihu, keď bola lekárom identifikovaná potreba zdravotníckeho výkonu (odborné vyšetrenie, operácia a podobne), do jeho uskutočnenia.
- Sumu poplatkov, ktoré pri tom musel pacient uhradiť.

## Úlohy

1. Špecifikovať hlavné prípady použitia a navrhnúť dátový model pre zbierané dáta.
2. Implementovať prototyp REST služby a klientské aplikácie na zadávanie dát.
3. Vytvoriť prehľad o bezpečnostných a právnych aspektoch (GDPR a podobne) prípadného nasadenia služby pre verejnosť.
4. Zistiť, ako by nasadenie služby bolo prijaté zo strany laickej verejnosti (potenciálnych pacientov), lekárov, zdravotných poisťovní a politických strán.
